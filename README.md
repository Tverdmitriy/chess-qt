# ♟️ Десктопная игра «Шахматы» на C++ и Qt 6

Учебный проект, демонстрирующий разработку интерактивного графического приложения с реализацией классической логики настольной игры.

## 🛠 Стек технологий
- **Язык:** C++17
- **Фреймворк:** Qt 6 (Qt Widgets)
- **Графика:** `QPainter`, `QPixmap`
- **Сборка:** CMake
- **Среда:** Qt Creator

## ✨ Реализованный функционал
- 🎨 **Кастомная отрисовка:** доска 640×640 px (клетки 80×80 px) с динамическим масштабированием через переопределение `paintEvent`.
- ♟️ **Полная логика ходов** для всех 6 типов фигур с учетом препятствий:
  - Пешка (включая двойной ход с начальной позиции и взятие по диагонали).
  - Конь (Г-образные ходы), Слон (диагонали), Ладья (прямые линии), Ферзь, Король.
- 🟢 **Визуальная обратная связь:** подсветка выбранной фигуры (желтый) и всех доступных клеток для хода (зеленый).
- 👑 **Превращение пешки:** при достижении последней горизонтали появляется `QInputDialog` для выбора фигуры (Ферзь, Ладья, Слон, Конь).
- 🏆 **Условие победы:** игра завершается при взятии короля соперника с выводом информационного окна и блокировкой дальнейших ходов.
- 🔄 **Смена хода:** автоматическое переключение между белыми и черными.

## 🏗 Архитектура приложения
Проект построен по принципу разделения ответственности (MVC-подобный подход):
| Компонент | Ответственность |
|-----------|-----------------|
| `Piece board[8][8]` | Модель данных: хранение состояния доски (тип и цвет фигуры). |
| `paintEvent()` | Представление: отрисовка доски, фигур и маркеров ходов. |
| `mousePressEvent()` | Контроллер: обработка кликов, валидация выбора и передача команд модели. |
| `getPossibleMoves()` | Бизнес-логика: алгоритм расчета допустимых ходов для конкретной фигуры. |

## 🚀 Как собрать и запустить
1. Убедитесь, что у вас установлен **Qt 6** и **CMake**.
2. Откройте файл `CMakeLists.txt` в Qt Creator.
3. Нажмите кнопку **Run** (или соберите через терминал: `cmake -B build && cmake --build build`).
4. *Примечание:* Для корректного отображения фигур убедитесь, что изображения (`.png`) находятся в папке `assets` и подключены через файл ресурсов `.qrc`.
